Detailed Description

template<typename T, typename E>
class gpcl::expected< T, E >

Represents either a value T or an error E.

expected<T, E> is a pointer-like class. Implicit conversion to bool returns true if there is a usable value. The unary * and -> operators provide pointer like access to the value. Accessing the value when there is an error has undefined behavior.
