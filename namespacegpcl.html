◆ json_errc

enum class gpcl::json_errc
strong

JSON error code enum type.

is_error_code_enum<json_errc> is specialized to have a const static member variable bool value = true, and make_error_code(json_errc) is overloaded to create error_code from json_errc. Thus json_errc is implicitly convertible to error_code.
